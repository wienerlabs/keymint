01 / Problem

Monetizing an API today is a mountain of plumbing.

Before you collect a single cent, you need an account system, an auth layer, a billing provider, a usage meter, and a webhook story. That's days of infrastructure for a $0.01 request.

01 — Onboarding

Sign-up tax

Every new user needs an account, an API key, a credit card on file. Each step kills conversion — especially for one-off agents.

02 — Billing

Stripe minimums kill micro-pricing

$0.30 + 2.9% per transaction means a $0.01 endpoint is uneconomical. So you batch, invoice, and break the per-request model.

03 — Trust

Off-chain logs are opaque

Did the payment really clear? Was usage counted correctly? Both sides have to trust your database — and there's no public proof.

04 — Agents

AI agents can't sign up

An LLM agent calling your API doesn't have a credit card or a session. The whole "log in to use" model breaks down.

02 / Solution

One small protocol, one stateless proxy, one chain.

Keymint reuses the dormant HTTP 402 status code as a machine-payable handshake — and settles every request on Solana in USDC. No database, no key management, no subscription state.

03 / How it works

Three exchanges. One transaction. Done.

01

Send Request

Agent calls a monetized endpoint. The proxy intercepts, looks up its price, and answers with HTTP 402 Payment Required.

GET /v1/...
02

Pay with OWS

SDK reads the payment instruction, builds an Anchor verify_and_pay tx, signs it with the wallet, and broadcasts to Solana.

402 → sign → send
03

Get Data

Agent retries with x-402-payment header. Proxy verifies on-chain, forwards to upstream, returns live data.

200 OK

The whole round trip takes ~2 seconds and leaves an immutable audit record on Solana — one PDA per payment.

06 / Components

Four parts. Each does one thing well.

Express server that intercepts requests, returns 402 with payment instructions, verifies on-chain receipts, and forwards to upstream APIs.

Node · Express · Anchor client

Anchor smart contract on Solana. verify_and_pay moves USDC, writes an audit PDA, and emits a PaymentEvent.

Rust · Anchor 0.31.1

Two-line client for AI agents. Handles 402 detection, OWS signing, transaction broadcast, and automatic retry.
